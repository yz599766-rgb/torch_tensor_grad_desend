四、`requires_grad` 开启梯度记录【Autograd 核心】


> 大白话：
> `requires_grad=False`（默认）：只是单纯算数字，**不记录计算过程，不求导**
> `requires_grad=True`：PyTorch 开启 “记账本”，记录这个张量后续所有运算，最后能自动求梯度。
> 只有**需要求导的变量（模型权重 w,b）**才打开 requires_grad,后面才能自动求导；输入数据 x 一般不开。、

代码：
w = torch.tensor(2.0, requires_grad=True)
x = torch.tensor(3.0)
y = w * x
print(y.grad_fn)

输出：`MulBackward0`
1. `Mul` = **Multiply，乘法**
代表 `y` 这个值，是通过**乘法运算**算出来的。
2. `Backward` = **反向**
代表这个运算**附带反向求导的公式**。
3. `0` 只是编号，不用管。

> 
> 一句话：`MulBackward0` 就是一个**小账本**，记录：这个结果来自乘法，并且存好了乘法对应的求导公式，等后面调用 `.backward()` 的时候拿出来算导数。
当你写 `y.backward()`，PyTorch 就找到这个`MulBackward0`，调用里面的求导公式算出梯度。

> w (2) × x (3) → y (6)
> ✅ 正向：做乘法，算出 y=6

这个乘法操作，PyTorch 会自动记下两件事：

- 正向公式：y=w*x
- 反向求导公式：\(\frac{dy}{dw}=x\)，\(\frac{dy}{dx}=w\)

```
w(requires_grad=True) ----┐
                          ├─MulBackward0 → y
x                         ┘
```

1. w 开启梯度追踪
2. 执行乘法，生成 y，附带`MulBackward0`这个反向节点
3. 调用`y.backward()` → 沿着`MulBackward0`里面的求导公式，反向计算 dy/dw
4. 算出梯度放到`w.grad`

```
y.backward()
# w的梯度，存在w.grad
print("w的梯度 dw：", w.grad) # 输出 tensor(3.)
```

✅ 和手动求导结果一致！

> 
> 重点规则：
> 
> 
> 1. 只有标量（单个数字）能直接.backward ()。如果 y 是向量，需要传`y.sum().backward()`
> 2. **每次 backward，梯度（就是线条的斜率）会累加！不会自动清零**，训练循环里必须 `w.grad.zero_()` 清零，不然梯度爆炸。这个是新手最大坑！






# Autograd（自动微分）到底是干嘛的，大白话

Autograd 就是 PyTorch 自带的**自动求导工具**。

> 
> 不用你手动推导高数求导公式，只要写正向计算代码，它自动帮你算梯度。

## 两件核心工作

1. **正向跑代码时：悄悄搭建【计算图】**
只要张量标记了 `requires_grad=True`，PyTorch 就会记录后续所有运算链路,生成计算图
比如 `y = w * x + b`，它记下：w 乘 x，再加 b，保存好每一步是什么运算（乘法、加法）。

> 
> 就是前面看到的 `MulBackward0`、`AddBackward0`，每个运算节点都附带反向求导公式。

2. **调用 `.backward()` 的时候：反向链式求导**
从最后的输出（一般是损失 loss）开始，沿着计算图往回走，用**链式法则**，自动算出：
损失对每一个 `requires_grad=True` 参数的导数，结果存进 `.g`




## 五、计算图（Computation Graph）大白话

上面例子 `y = w * x`
计算图长这样：

```
w ----┐
      ├─> *  ──> y
x ----┘
```

- 叶子节点：w（requires_grad=True，自己创建的，叶子）；x（叶子，不开梯度）
- 中间节点：乘法操作 Mul，y 是输出节点
正向传播：从左往右算 y
反向传播：调用 backward，从右往左，链式法则求各个导数。

> 
> Autograd 本质：自动构建这个图，自动链式求导，不用你手推公式。

#重点
#本节课的核心就是，学会利用梯度下降，更新参数，找到最合适的参数，让预测结果，和手里的真实数据最接近，最符合，最拟合
# 梯度下降什么（大白话）> 核心：**利用梯度，不断微调模型参数，让预测结果越来越接近真实答案**。


想象你站在一座山上，目标走到**山谷最低点**（损失最小的位置）。

- 山的高度 = 损失 loss
- 你的坐标 = 模型参数（w、b）
- **梯度** = 脚下当前位置，山坡倾斜方向：告诉你往哪个方向走，高度会下降（就是斜率，决定w往哪里走，loss可以下降）
- **梯度下降**：沿着梯度反方向，每次迈一小步，不断往下走，直到走到谷底。

公式：

w = w - lr .w.grad
lr：学习率，就是你**每一步迈多大**
w.grad：梯度，山坡倾斜程度
减去梯度：往山谷方向更新参数



# 放到代码里的流程

1. 拿当前参数 w，计算预测值 y_pred=w*x
2. 算损失 loss：预测值和真实值差多少
3. `loss.backward()`：Autograd 自动求梯度，知道 w 往哪边改能减小 loss
4. w = w - lr. w.grad：更新 w（下山一步）
5. `w.grad.zero_()`：清空梯度，准备下一轮
6. 循环很多次，w 慢慢收敛到合适的值





# 拟合（大白话）

**拟合 = 找一条曲线（直线是最简单的曲线），让这条线尽量贴近手上的真实数据点。**

## 举刚才例子：拟合直线 y=w * x

我们手上有一批真实采集的数据：

表格

| x | y 真实值 |
| --- | --- |
| 1 | 5 |
| 2 | 10 |
| 3 | 15 |
| 4 | 20 |

肉眼一看，规律就是 y=5x
但是**计算机不知道这个公式**，它只能猜一个式子 y=w * x

- 一开始猜 w=2，得到直线y=2x，这条线离真实数据很远，误差很大。
- 梯度下降不断修改 w，一点点调整这条直线的倾斜程度。                (更新w，找到最合适的w的过程就是梯度下降)             
- 最后 w≈5，这条线刚好穿过所有数据点 → **拟合成功**。

> 简单一句话：**拟合就是调整模型参数，让模型预测出来的值，尽可能贴近真实观测数据。

# 六、实战：手动实现简单梯度下降（不用 nn.Module，纯手搓）

目标：拟合一条直线 y = w * x
真实关系：假设真实 w=5，也就是 y=5x
我们给一堆 x，带一点噪声的 y 数据；（手里的真实数据）
我们初始化猜测 w，不断用梯度下降更新 w，让 w 慢慢逼近 5。

### 梯度下降公式回顾

损失 MSE：\(loss=(y_{pred}-y_{real})^2\)

\(y_{pred}=w\cdot x\)

\(\frac{d(loss)}{dw}=2\cdot (w x - y_{real}) \cdot x\)

更新规则：

\(w = w - lr \cdot \frac{d(loss)}{dw}\)
lr = 学习率，控制每次走多大一步。

完整可运行代码，带注释：

```
import torch

# 1. 准备数据集
x = torch.tensor([1.,2.,3.,4.,5.])
y_real = torch.tensor([5.,10.,15.,20.,25.]) # 真实 w=5

# 2. 初始化待训练参数w，开启求导
w = torch.tensor(1.0, requires_grad=True)
lr = 0.01 # 学习率
epoch = 20 # 迭代轮数

for i in range(epoch):
    # 正向传播：算预测值，算loss
    y_pred = w * x
    loss = torch.mean((y_pred - y_real)**2) # MSE均方误差

    # 反向传播：自动求梯度
    loss.backward()

    # 更新参数！这一步必须放在 torch.no_grad() 里面
    # 因为更新w属于手动赋值，不要让autograd记录这次操作
    with torch.no_grad():
        w -= lr * w.grad

    # 梯度清零！！！极其重要，不清零梯度会叠加
    w.grad.zero_()

    if i%2 ==0:
        print(f"轮数{i:2d} | w={w.item():.3f}, loss={loss.item():.3f}")
```

### 运行结果解读

一开始 w=1，loss 很大；随着迭代 w 慢慢靠近 5，loss 越来越小。

> 
> 关键点解释：
> 
> 
> 1. 参数更新 `w -= lr * w.grad` 必须包在`with torch.no_grad()`，不然更新这个操作也会被记入计算图，报错。
> 2. `w.grad.zero_()` 梯度清零，每一轮梯度重新算，**不清零梯度累加，参数直接跑飞**。
> 3. `w.item()`：把张量里单独的数字拿出来变成普通 python 浮点数。
